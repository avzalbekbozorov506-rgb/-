# День 2 — чт 23.10.2026

## Ролик 2.1 — 10:00 — «Угадай: кто лжёт?» (~40 с, интерактив) 
**Хук:** ОДИН ИЗ ТРОИХ ЛЖЁТ. КТО?
**Озвучка:** (Пример, вымышленная история)
Один из троих лжёт. | Кто? // Пропали часы хозяина. | Дождь шёл с девяти до десяти. // Горничная: «Я мыла посуду». | Руки у неё красные и мокрые. // Племянник: «Читал в кабинете». | На столе его чашка и книга. // Сосед: «Гулял в саду весь вечер». | Туфли у него чистые и сухие. // Подумай три секунды. // Лжёт сосед. | Под дождём час не погуляешь | с сухими туфлями. // Ложь чаще всего ломается о мелочь. // Отправь тому, кто думает, что умнее всех. | Подпишись.
**Кадры:** три портрета PD (Met: горничная — Вермеер/Шарден «Молочница»-тип; юноша — Рембрандт; мужчина — Халс); крупно туфли — Ватто/Веласкес (фрагмент, Met); дождь — Хиросигэ «Внезапный дождь» (Met/AIC); текст «ПРИМЕР» на экране.
**Описание:** Пример (вымышленная история). Один из троих лжёт — кто? Мелочь выдаёт лжеца. Не медицинская рекомендация. Отправь тому, кто думает, что умнее всех. Подпишись.
**Источники:** авторская загадка; идея «улика-несостыковка» — общий приём жанра.

## Ролик 2.2 — 13:30 — «10 запретов для детектива» (~28 с)
**Хук:** ДЛЯ ДЕТЕКТИВОВ ПИСАЛИ ЗАПРЕТЫ.
**Озвучка:**
Для детективов написали десять запретов. // Тысяча девятьсот двадцать девятый. | Священник Рональд Нокс решает: | никаких неизвестных ядов, | никаких чудесных совпадений. | Сыщик не должен быть убийцей. // Читателю положено знать то же, что и сыщику. // Кр+исти состояла в Клубе детективов. | И всё равно умела удивлять. // Отправь тому, кто любит правила и хитрости. | Подпишись.
**Кадры:** Wikimedia: портрет Рональда Нокса 1920-х (проверить PD); страница «Decalogue» (цитируем кратко, свой перевод); Хаммерсхёй; лупа/перо — гравюры (Met).
**Описание:** В 1929 году Рональд Нокс сформулировал «Десять заповедей детектива». Кристи входила в Детективный клуб (основан 1930; президент 1957–1976). Источники: R. Knox, «Introduction» к «Best Detective Stories of 1928–29» (1929); сайт Detection Club. Отправь тому, кто любит правила и хитрости. Подпишись.
**Проверить:** формулировки заповедей (свой перевод), годы клуба.

## Ролик 2.3 — 18:30 — «Мисс Марпл сравнивала людей» (~52 с)
**Хук:** МАРПЛ НЕ ИСКАЛА УЛИК. ОНА СРАВНИВАЛА.
**Озвучка:**
Мисс Марпл не искала улик. | Она сравнивала. // Пожилая дама из деревни Сент-Мэри-Мид | ни разу не была в большом деле. | Зато знала всех соседей. // И каждый раз говорила: | это точь-в-точь как | с мясником, с почтальоном, с племянником. // Так работает опыт. | Лицо новое, | а схема старая. // Ты тоже так делаешь. | Новый знакомый обещает горы, | и ты вспоминаешь прежнего. // Это не подозрительность. | Это память, которая спасает. // Но помни: схема лишь подсказка. | Проверь факты. // Отправь тому, кто вечно наступает на те же грабли. | Подпишись.
**Кадры:** Брейгель «Крестьянский танец»/«Времена года» (Met/Wikimedia — деревня, PD); вязание — Милле/Вермеер «Кружевница» (Лувр, PD); сельская улица — Констебл; схема «человек → схема» (своя графика).
**Описание:** Мисс Марпл распознавала людей по сходству с деревенскими знакомыми. Это общий принцип опыта: узнавать схемы. Источники: А. Кристи, «Убийство в доме викария» (1930) и «Занавес»-эпоха цикла о Марпл (общие мотивы, не цитата). Отправь тому, кто вечно наступает на те же грабли. Подпишись. Не медицинская рекомендация.
**Проверить:** упоминания «человеческая природа везде одна» — в «Убийстве в доме викария» (гл. 7?). Если не подтвердится — убрать конкретику.

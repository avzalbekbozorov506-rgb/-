# Часть 6. Итоговый контрольный список перед публикацией (на каждый ролик)

**Права**
- [ ] В ролике нет цитат из книги и пересказа глав; нет историй пациентов автора.
- [ ] Нет обложки книги, фото автора, скриншотов книги.
- [ ] Картины — CC0/PD (источник и лицензия записаны); `used_art.py` — повторов нет.
- [ ] Музыка — лицензия записи и композиции подтверждена, ссылка в `rights.txt`; иначе без музыки.
- [ ] Нет логотипов и интерфейсов чужих приложений (только макеты).

**Достоверность**
- [ ] Каждая цифра и исследование сверены с оригиналом.
- [ ] Каждая приписанная Лембке мысль сверена с книгой (или убрана).
- [ ] Гипотезы названы гипотезами; нет диагнозов и обещаний; нет «дофамин — гормон счастья».
- [ ] Медицинские темы (холод, отказ от веществ) — с оговоркой о враче.

**Качество**
- [ ] Хук ≤ 2 с; плашка = первая фраза = обложка.
- [ ] Есть повторный крючок ≈ 25 с и ясная последняя мысль.
- [ ] Озвучка проверена (`check_text.py`, Whisper), ударения и числа верны.
- [ ] Субтитры в безопасной зоне; громкость −14 LUFS.
- [ ] Описание с дисклеймером, 3–5 хештегов, закреп с источниками.
- [ ] Ролик понятен сам по себе (не ссылается на «вчерашний»).

**Публикация**
- [ ] Ваше явное «да» на ролик и время; нет конфликта с вашими внутренними постами.
- [ ] Интервал между публикациями ≥ 3 ч; ночью не публикуем.
- [ ] Отметка ИИ-контента/синтеза голоса по правилам платформы.
- [ ] Поставлено напоминание снять метрики через 24 ч и 7 суток.

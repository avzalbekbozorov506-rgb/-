# glare_1 — визуал: «Встречные фары слепят. Почему?» (Простым языком, ночная трасса от лица водителя)

Сценарий: `reels/scripts/glare_1.md`. Референс (35 с, камеры средней скорости): взяты только идея и структура — ночная трасса в перспективе с фонарями, неон, шапка с главой, спидометры, карточки A/B, HUD-рамки, субтитры по 1–2 слова. Графика своя, кодом. Без ника, без логотипов, без платного. Ничего не рендерилось.
Таймкоды ниже — по таблице сценария (≈ 85–90 с); реальные берутся из `PHRASES` после синтеза, поэтому в конфиге везде `T(i,k)`/`P(i,lt,k)`, а не секунды.

## 1. Концепция
- Одна идея: **вид из салона ночью + «диафрагма»-зрачок в углу**. Дорога — тёмная 3D-перспектива, свет — единственный герой. Зритель сначала «ослеплён» (белая вспышка в кадре 1), в конце тот же кадр, но взгляд на правом крае: дорога читается, зрачок спокойный.
- Палитра: фон `BG (6,9,18)` как в wifi_1; дорога/обочина сине-серые (14,20,34)–(40,52,80); встречный свет — тёпло-белый (255,244,220) с голубой каймой; неон HUD — NEON (80,235,205), GOLD (255,214,60) для чисел и субтитров, RED (255,80,60) для опасности, BLUE (60,150,255) для «безопасного» (правый край, ближний свет).
- Почему так: тема — свет и темнота, значит, контраст «чёрное против белой вспышки» сам делает хук; цифры (мм, минуты, м/с, метры) живут в HUD, как в референсе; взгляд на правый край показывается подсветкой края дороги — один понятный образ вместо схем.
- Шапка как у референса, но свои слова: слева «ПРОСТЫМ ЯЗЫКОМ · ФАРЫ», справа «глава 02/06» + слово-тема (`ВОПРОС / ЗРАЧОК / ВУАЛЬ / ТЕМНОТА / РАСЧЁТ / ЧТО ДЕЛАТЬ`). Использовать `HEAD` движка + свою `chap()` из wifi_1 (там «n / 06» уже есть; добавить слово-тему справа золотом).

## 2. Единые правила
- Кадр 1080×1920; важное в y 240–1680. Шапка y≈300, субтитры сверху по центру (как референс): `SUB_STYLE = "words"`, `WORDS_Y = 420` (проверить, что не залезает на шапку; если да — 450), `WORDS_SIZE = 92`, жёлтые слова, ещё не сказанные — серые (если опция `words` этого не умеет, оставить только жёлтые — проверить `text_layer` в `cinema_engine.py`).
- Нижняя треть (y 1300–1680) — спидометр/карточки; ниже 1680 только мелкая подпись «Не инструкция по ПДД» (появляется с гл. 05).
- Запрещено: читаемые госномера, реальные марки/логотипы на машинах, лица людей, крупные «пугалки» с авариями, кровь, анатомические подробности глаза. Машины — силуэты: тёмный корпус, красные/белые огни, блик по крыше.
- Глаз — схема: овал-веко, радужка кольцом, круглый зрачок-диафрагма с делениями (как ирис фотообъектива). Без прожилок, без сетчатки крупным планом; «внутри глаза» — условный круг с лучами и молочной вуалью.
- Текст на экране — только из раздела «Надписи на экране» сценария (грамматика проверена там же). Числа на экране: 8 мм / 4 мм, 10–45 мин, 90 км/ч = 25 м/с, 2 с = 50 м, 3 с = 75 м, 150 м. Всегда писать «п. 19.2», не 19.4.
- Соседние сцены не повторяют приём: чередуем вид из салона / крупный глаз / схема / вид сверху / спидометр / карточки.

## 5. Промпты для картинок
Основной путь бесплатный: всё рисует код (`road_kit.py`). Запасные платные AI-промпты — **только по разрешению пользователя**:
1. Хук: `night highway first-person from driver seat, two blinding oncoming headlights, strong lens flare, dark blue road, 9:16, no text, no logos, no license plates, no watermark`.
2. Глаз: `schematic stylized eye, large round pupil like camera iris diaphragm, dark blue background, neon teal outline, minimal vector style, 9:16, no text, no medical detail`.
3. Дорога с силуэтом на обочине: `dark night road, faint pedestrian-like silhouette on roadside, headlights haze veil, 9:16, no faces, no text`.
Использовать не планируем.

## 6. Анимация по сценам (движок)
Движок: сцена-функция `(lt, D)` возвращает RGBA; экранный зум конфигом не нужен — наезд делает `fin()`. Эквиваленты: zoom 1.00→1.06 (сц. 0,3,12), 1.00→1.03 (4,6,9,13). `FX` не нужен (всё в коде). Что НЕ должно происходить: дёрганье зрачка (только `ease`), морфинг машин, мерцание дорожной разметки (скорость разметки постоянна ≈ `lt·6` z/с), нечитаемые номера (на силуэтах номера не рисовать).

## 7. Монтаж и звук
- Темп: смена картинки каждые 3–5 с, внутри сцены — действие по слову. Склейки: жёсткие на вспышках/ударных словах (0→1, 3, 10→11), наплывы `XF = 0.3` на спокойных.
- `TAIL=0.3`, `GAP=0.28`, `LEAD_N=0.2`, голос `_voice3` с `STYLE` для эмоций: «Встречные фары слепят.» — rate 1.0, pitch +; «Теперь цифры.» — пауза after_ms 250; «Что делать?» — длинная пауза (`qmul`).
- Музыка: `music/ogv_aria.mp3` под голос (стандарт серии «Простым языком»).
- SFX кодом (`SFX(STARTS, PHRASES, DURS, SR)`): «вжух» при вспышке фар (0, 3), тихий тик на каждую секунду счётчика (сц. 10), «клик» карточек (11), мягкий «пинг» подписи (16).
- Субтитры: по 1–2 слова, жёлтые; шрифт Inter Bold.

## 8. Риски рендера и фактов
- Дорога + блум + HUD на кадр: целиться в ≤ 0,8 с; блум считать на 540×960. Параллельный рендер (WORKERS=4) уже есть — ролик 85 с ≈ 10–14 мин; запускать через `setsid nohup`, следить, что процесс жив.
- Сложность — сцена 4 (схема глаза) и сцена 10 (вид сверху с вуалью): делать простыми 2D-слоями, не 3D.
- Факты: п. 19.2 (не 19.4); «скоси взгляд правее» — совет журнала «За рулём», не норма ПДД; цифры 10–45 мин и 4/8 мм — вторичные источники (в описании со ссылками, уже есть в `glare_1.md`). Не медицинская рекомендация.
- Озвучка проверять `check_voice_fw.py`: «миллиметров», «аварийку», «вуаль», «пункт девятнадцать, два».

# blackhole_1 — визуал (моушен-графика, всё рисуем кодом, 0 руб.)

Сценарий: `reels/scripts/blackhole_1.md`. Путь: отдельный генератор кадров `art_tools/gen_blackhole.py` (numpy+PIL, 1080x1920, 30 fps, функция `frame(t)`), кадры в mp4 через ffmpeg, затем озвучка/субтитры/музыка как в проекте. Ничего не рендерилось. Не путать с движком картин: `cinema_engine.py` рисует картины с зумом, а здесь кадры считаем сами (проверить, можно ли подать готовый mp4 как "картину" сцены; иначе склеить ffmpeg + `finalize.py`).

## 1. Концепция
Тёмный космос, как "схема из учебника, ожившая в ночи". Единая идея: невидимое видно только по свету вокруг, поэтому весь ролик чёрный, а единственный источник цвета -- один оранжево-золотой "свет" (аккреционный диск, кольцо, подчёркивания). Зритель с первой секунды видит чёрный круг в светящемся кольце и ждёт "а почему это не дыра". Кольцо рядом с чёрным провалом = обложка, хук и финал.

## 2. Стиль и правила
- Фон: градиент #05070F -> #0B1226, мелкие звёзды (seed, 150 шт., мерцание +-20 %), виньетка по краям.
- Акцент (единственная яркая краска): оранжевый #FF8A1F, горячее ядро #FFD27A, "холодная" сторона диска #5AA7FF только в сцене 9 (нагрев синий -> оранжевый). Белый #F2F4FA для текста и схем, приглушённые линии сетки #3A4A78.
- Шрифты: Cormorant Garamond Bold (`reels/fonts`) для плашек и крупных слов; Inter в `reels/fonts` нет -- для цифр/линеек использовать гротеск через `SUB_SANS` движка или положить Inter (OFL) в `fonts/` (проверить). Плашка 120-140 px, подпись 56-64 px, обводка тёмная 6 px, тень.
- Линии 6-8 px со свечением (gaussian blur 18 px, складывается additive). Никаких картинок из сети, никаких людей, без латиницы в озвучке; цифры (11 км/с, 3 км, 9 мм, 2019, 2022) -- только на экране.
- Композиция: главный объект по центру x=540, y=760-1050 (центр зоны 240-1680 слегка выше), текст-плашка y 260-520, подпись-схема y 1150-1330, субтитры с y~1130 (59 %) не перекрываем объектом, подпись сцены ставим выше (y 1020-1100) или заменяем субтитром.
- Easing: все движения easeInOutCubic; "сжатие" и "падение" -- easeInQuad (ускорение); пульсации -- sin. Смена сцены каждые 3-6 с; в сценах 4, 5, 9 по 2-3 внутренних шага.
- Запрещено: случайные надписи, мелкий шрифт < 48 px, красное (резервируем для "опасно"-акцента не используем), пересвет центра (clamp 0..255, тон-маппинг 1-exp(-x)).

## 3. Три "вау"-момента
1. Сцена 9, 40-47 с -- аккреционный диск с линзированием: наклонный диск (эллипс, доплеровское усиление яркости слева), поверх него изогнутая "дуга" диска за дырой (линзированное изображение задней части над и под тенью). Считаем пикселями: для каждой точки в полярных координатах радиус-вращение, яркость по r^-2, смещение яркости cos(phi) для эффекта Доплера, вторичное кольцо = отражение диска, радиус ~1.3 * r_тени.
2. Сцена 5, 17-23 с -- горизонт-тень: пунктирная окружность "выжигается" по часовой, луч света изнутри кривится по параболе и возвращается, внешний уходит прямо; в момент пересечения пунктир вспыхивает белым, фон на 3 кадра затемняется -- и тут акцент музыки (см. 6).
3. Сцена 8-9 -- Земля -> горошина -> первый снимок как схема: нарисованное нами кольцо M87* (асимметричное, ярче снизу-справа, тёмный центр, подпись "схема", не фото) проявляется из шума: сначала диск, потом "размытая точка" сходится в чёткое кольцо (имитация сборки снимка).

## 5. Программы для кадров (план кода, без запуска)
- `art_tools/gen_blackhole.py`: `frame(t) -> PIL.Image`; слои: фон+звёзды, сетка, объекты (круги/дуги -- PIL ImageDraw с 2x суперсэмплингом), свечение (blur+add), диск (numpy по полярным координатам), текст (PIL, Cormorant Bold).
- Сцены -- функции `scene_N(t_local)`, переходы -- `blend(a, b, k)`, iris-маска `circle_mask(r)`.
- Кэш звёзд и сетки; оценка времени рендера: ~1800 кадров, 0.3-0.5 с на кадр -> 10-15 мин (учитывать для запуска фоном).

## 6. Звук и монтаж
- Голос `_voice3` (Vosk диктор 4, rate 0.88). Проверить `check_text.py` и длину: цель <= 60 с; запас -- убрать сцену 10.
- Музыка CC0/PD из `music/`: Сук "Медитация" (`suk_meditation.mp3`) или Григ "Смерть Осе" -- низкая громкость (-22 дБ под голосом, ducking). Лучший вариант для космоса -- Сук (тянущиеся струнные). Вторая -- `ogv_aria.mp3` (CC0, уже в rights.txt).
- Акценты: сцена 5 -- тишина 0.3 с перед вспышкой горизонта и низкий "бум" (синтез sin 55 Гц, затухание 1.2 с, генерируем сами); сцена 7 -- короткий "свист" пылесоса (шум, band-pass, 0.5 с), обрывается на слове "не"; сцена 9 -- нарастающий шум-свист (rise) под "первый снимок"; финал -- мягкий "тон" при появлении кнопки.
- Субтитры: караоке, крупнее 62 px, не закрывают схему.
- Описание: из `blackhole_1.md`, пометка "мысленный опыт" для сжатия Солнца; "схема, не фото". Закреплённый комментарий с источниками (EHT 2019/2022, NASA) -- вручную.

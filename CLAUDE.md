# Проект: Reels для Instagram @mysli.vekov («Мысли веков»)

Отвечай пользователю по-русски, коротко и просто. Пользователь работает с телефона.

## Как начать в новой сессии

1. `bash reels/setup.sh` — ставит torch (CPU), scipy, transformers, скачивает голос Silero `reels/v5_ru.pt` (~145 МБ, в git не хранится).
2. Все команды запускать из папки `reels/`.

## Что работает (по статистике аккаунта)

- Лучший формат: **картины эпохи + известное имя + «5 правил/мыслей»** (Макиавелли — 210 просмотров).
  Мультфильмы (Весы, Гвозди, Лисица и лев) набирают заметно меньше.
- Длина 50–60 с. Хук в первую секунду. Мини-хуки внутри («самое циничное», «бьёт больнее всего»).
- Концовка — призыв: «Напиши номер в комментариях».
- Один ролик в день, не больше.

## Команда агентов (`.claude/agents/`)
Главная сессия работает как **AvzalBos** — координатор (инструкция: `.claude/agents/avzalbos.md`). На просьбу «сделай ролик»
следуй ей: раздавай работу агентам через общий файл `reels/work/<имя>/handoff.md`.
Цепочка: `content-manager` (тема, сценарий, факты, описание) → `montazhyor` (картины, превью) + `sound-engineer` (озвучка по Whisper)
параллельно → `montazhyor` (рендер, HQ, обложка) → `qa-checker` (голос, слова, картинки, субтитры, факты) →
ошибки возвращаются нужному агенту, до 3 кругов → готовое отдаётся пользователю.
Стандарты студии (цифры: безопасные зоны, громкость, хуки, факты, серьёзность ошибок) — `reels/PLAYBOOK.md`;
уроки прошлых роликов — `reels/LESSONS.md` (Бос дописывает после каждого ролика).
Имена: Авзалбек-Бос, Авзалбек-Контент, Авзалбек-Монтаж, Авзалбек-Звук, Авзалбек-Контроль.
**Офис** (пользователь смотрит, кто что делает): https://claude.ai/artifact/GAsw47YZfG491RxmWni2pi — страница `office/index.html`,
данные в базе артефакта (`agents`, `log`, `office/current`). Бос обновляет офис при каждой передаче работы (см. avzalbos.md).

## Как собрать новый ролик (стиль «картины»)

Образец: `reels/configs/seneca_rules.py` и `reels/configs/machiavelli_rules.py`. Копируй конфиг и меняй:
- `HEAD` — шапка (имя, подзаголовок); `HOOK = ("ТЕКСТ\nПЛАШКИ", секунды)` — красная плашка-хук; `HOOK_Y` — так, чтобы не закрывать лицо.
- `SCENES` — `(озвучка, "SUB", метка, имя_картины_из_art/, подпись_картины, (zoom0, zoom1, (fx0, fy0), (fx1, fy1)))`.
  В озвучке `|` делит фразы (каждая — отдельный субтитр), `+` перед гласной — ударение (`Макиав+елли`, `пр+авило`).
- Голос (утверждён пользователем — «голос №3»), НЕ менять без просьбы:
  `SPEAKER = "eugene"`, `SSML = dict(pitch=0.93, tempo=0.86, dot=420, dash=300)`,
  `LEAD0, FADE_IN, GAP, TAIL = 0.05, 0.12, 0.42, 0.9`.
- Субтитры (утверждены): `SUB_STYLE, SUB_FONT, QUOTE_SIZE, SUB_CHARS = "karaoke", "Bold", 70, 24`, `TEXT_DY, BOT_ALPHA = 120, 236`.

Сборка:
```
python3 cinema_engine.py configs/<имя>.py <имя>.mp4 0.4,10,20,30   # сначала превью-кадры в work/<имя>/pv_*.png
python3 cinema_engine.py configs/<имя>.py <имя>.mp4                # полный рендер (~7 мин), плюс <имя>_light.mp4
```

### Голос (с 13.10.2026): Vosk TTS — «студийный», ударения по словарю
Пользователь жаловался на ошибки произношения Silero. Теперь в конфиге: `VOSK = dict(speaker=4, rate=1.0, dot=340)`
(диктор 4 — мужской; `rate` 0.9 — спокойнее, 1.0 — для 5 правил), `GAP, TAIL = 0.3, 0.75`. Установка: `pip install vosk-tts`
(модель ~750 МБ скачивается сама). Кавычки «» движок убирает сам. Если `VOSK` нет — работает Silero (голос №3 / `PROSODY`).

### Финал, оживление, эффекты
- `python3 finalize.py <имя>` — громкость −14 LUFS (пик ≤ −1 dB), облегчённая копия и `hq/<имя>_hq.mp4` ≈28,5 МиБ.
- «Живые картины»: `FX = {картина: [("snow"|"rain"|"shimmer"|"glow", {...})]}` в конфиге.
- Оживление фигур без нейросетей-генераторов: `PUPPET` в конфиге + `python3 animate_art.py configs/<имя>.py`
  (SAM вырезает фигуры, `pip install opencv-python-headless`), клипы в `work/clips/`, `CLIPS = {...}` подключает их.
- Бесплатные генераторы видео (Wan/LTX на Hugging Face) без аккаунта упираются в лимит; нужен токен `HF_TOKEN` в окружении.

### Обязательная проверка озвучки (пользователь жаловался на «ошибки»)
`python3 check_voice.py configs/<имя>.py` — Whisper распознаёт каждую фразу. Синтезатор глотает окончания
у коротких фраз («Правило первое» → «правила первая»): переставляй слова («Первое правило»), добавляй `+`,
проверяй варианты: `printf 'вариант 1\nвариант 2\n' | python3 check_voice.py configs/<имя>.py -`.
Пока все фразы не распознаются правильно — не рендерить.

### Картины
Только public domain: The Met Open Access (CC0). Поиск: `https://collectionapi.metmuseum.org/public/collection/v1.1/search?q=...&hasImages=true&medium=Paintings&limit=12`,
объект: `.../public/collection/v1/objects/<id>` — брать только `isPublicDomain: true`, `primaryImage`.
Сохранять в `reels/art/<имя>.jpg` (≤2600 px), автора и название добавлять в `reels/art/credits.json`.
Не использовать картины, уже бывшие в опубликованных роликах.

## Обложки
- Кликбейт-обложка (красная плашка + штамп + название): функция `make_click` в `reels/make_covers_click.py`;
  отдельные скрипты-примеры: `make_cover_click.py` (Макиавелли 2), `make_cover_seneca.py`.

  в `reels/hq/<имя>_hq.mp4` (bitrate = 28.5·8·1024·1024/1000/длительность − 192 кбит/с, `-preset slow -tune film`) и отправлять её,
  а не `_light`. Полный оригинал остаётся в `reels/<имя>.mp4`.

- Описание без хештегов (пользователь просил без них), с вопросом к зрителю в конце.

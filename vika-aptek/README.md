# Аптека: старт — личный учебный сайт

Учебный помощник для Виктории на первые 2–3 недели работы фармацевтом: общая логика учётной программы на базе 1С, тренажёр «Касса», ассортимент, карточки, план на 14 дней, словарь, шпаргалка и сценарии общения с покупателем.

Сайт работает **без интернета** и **ничего никуда не отправляет**: в нём нет внешних шрифтов, CDN, аналитики и форм отправки. Все данные хранятся только в браузере телефона.

> Учебная модель. В вашей аптеке окна и кнопки могут отличаться. Сверяйтесь с инструкцией работодателя и наставником.
> Фармацевт не ставит диагнозов и не назначает лечение. Ограничения — в [LIMITS.md](LIMITS.md).

## Что внутри

| Файл | Назначение |
|---|---|
| `dist/vika-aptek.html` | **Готовый сайт одним файлом** — его и нужно открыть на телефоне |
| `src/` | Исходники: `index.html`, `style.css`, `js/*.js` (данные уроков, ассортимента, словаря, тренажёр, приложение) |
| `build.mjs` | Сборка `src/` → `dist/vika-aptek.html` |
| `tests/check.mjs` | Автопроверка в Chromium: офлайн, ссылки, ширина телефона, тёмная тема, тренажёр, экспорт/импорт |

## Как открыть на телефоне (приватно)

Сайт нигде не публикуется. Нужно просто передать себе один файл `dist/vika-aptek.html` (≈ 320 КБ):

1. Скачайте файл `dist/vika-aptek.html` из репозитория на компьютер (или сразу на телефон).
2. Передайте его на телефон любым приватным способом: кабелем USB, через «Избранное» / «Сохранённые сообщения» в мессенджере (отправка самой себе), по AirDrop / Nearby Share или через личное облако.
3. **Android:** откройте файл из приложения «Файлы» → «Открыть с помощью» → Chrome (или другой браузер). Сохраните страницу в закладки.
4. **iPhone:** сохраните файл в приложение «Файлы» и откройте его (нажатие на файл → «Поделиться» → открыть в браузере, если предварительный просмотр не запускает скрипты). Если в предпросмотре «Файлов» сайт не реагирует на нажатия — откройте в Safari.
5. Открывайте сайт **всегда из одного и того же места одним и тем же браузером** — прогресс привязан к браузеру и к расположению файла. Если переместили файл — восстановите прогресс из резервной копии.

Тема (светлая / тёмная / как в системе) переключается кнопкой с солнцем вверху.

## Резервная копия прогресса

Прогресс, заметки, вопросы наставнику, «Мой ассортимент» и карточки лежат только в браузере. Очистка данных браузера или смена телефона их удалит.

1. Внизу «Ещё» → «Резервная копия» → **«Скачать резервную копию»** — сохранится файл `vika-aptek-kopiya-ГГГГ-ММ-ДД.json`.
2. Если скачивание не сработало (бывает на iPhone), нажмите «Показать как текст» → «Скопировать» и вставьте текст себе в заметки или сообщение самой себе.
3. Восстановить: там же «Выбрать файл .json» (или «Вставить текст копии вручную»). Текущие данные на устройстве будут заменены.

Совет: делайте копию раз в 2–3 дня и после крупных изменений в «Моём ассортименте».

## Как пополнять «Мой ассортимент»

Это главный способ выучить ассортимент **своей** аптеки — общий каталог его не заменяет.

- **На телефоне:** «Ассортимент» → «Мой ассортимент» → «+ Добавить позицию». Поля: название, МНН, форма, дозировка/фасовка, группа, особенности, место на витрине, заметки, «Учить в карточках».
- **Списком через таблицу:** «Шаблон CSV» → откройте в Excel / Google Таблицах / «Таблицах» на телефоне, заполните строки (разделитель — точка с запятой; первая строка — заголовки: `Название;МНН;Форма;Дозировка;Группа;Особенности;Место на витрине;Заметки`) → сохраните как CSV (UTF-8) → «Импорт CSV». Повторы (одинаковые название + дозировка + форма) пропускаются.
- **Выгрузка:** «Экспорт CSV» — чтобы отредактировать на компьютере или показать наставнику.
- Сведения МНН берите с упаковки и из инструкции. **Не вносите** цены, наценки, коды и названия поставщиков, данные покупателей и другие внутренние сведения работодателя.
- Добавленные позиции автоматически появляются в карточках (колода «Мой ассортимент») и в таблице «МНН — торговые названия — форма — дозировка» (Ассортимент → «МНН, синонимы и аналоги»).

## Для разработчика

```bash
cd vika-aptek
node build.mjs            # собрать dist/vika-aptek.html
node tests/check.mjs      # проверить собранный файл (нужен Playwright + Chromium)
```

Правка контента — в `src/js/data-*.js`, после правки пересоберите. Исходники можно открыть и напрямую: `src/index.html`.

Не включайте GitHub Pages и не делайте репозиторий публичным — сайт предназначен только для личного использования.

1. Тема: если не задана — предложи по статистике (лучше всего: картины эпохи + известное имя + «5 правил/мыслей»),
   не повторяя опубликованное (список в CLAUDE.md).
2. Конфиг `configs/<имя>.py` по образцу: 7 сцен (хук, 5 правил, концовка «Какое правило — про тебя? | Напиши номер в комментариях.»),

3. Описание поста: без хештегов, с вопросом к зрителю в конце.
4. Текст обложки: хук (2–3 строки КАПСОМ), слово-штамп, название, подзаголовок. Только правда.

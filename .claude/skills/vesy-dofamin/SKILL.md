## Как собрать ролик недели (по образцу `dopamine_1/2/3`)
1. Окружение новой сессии: `pip install --break-system-packages scipy numpy pillow vosk-tts faster-whisper language_tool_python torch`; `bash reels/fetch_music.sh`; `curl -o reels/v5_ru.pt https://models.silero.ai/models/tts/ru/v5_ru.pt` (движок грузит его при старте). Модель голоса Vosk (≈750 МБ) качается при первом запуске — **не запускать два процесса одновременно до первой загрузки** (портится кэш `/root/.cache/vosk`; лечится удалением и одной загрузкой `python3 -c "from vosk_tts import Model; Model(model_name='vosk-model-tts-ru-0.9-multi')"`).
2. Взять полный сценарий из `dayN.md`, написать `reels/configs/dopamine_<N>.py` по образцу: `from _voice3 import *` (голос: Vosk диктор 4, rate 0.88), `HEAD`, `HOOK` (плашка = первая фраза), `HOOK_SIZE = 80`, `HOOK_Y = 520`, `GAP = 0.35`, `TAIL = 1.0`, `MUSIC = ("music/ogv_aria.mp3", 0)`, `SCENES` — анимированные сцены функциями `f(lt, D) -> PIL RGBA 1080×1920` (своя графика) и/или картины The Met. Субтитры: безопасная зона, 2 строки.
3. Картины: `python3 art_tools/met_search.py …`, `met_fetch.py id`, `met_sheet.py` (смотреть глазами), обязательно `python3 art_tools/used_art.py configs/<имя>.py` → «повторов нет». Движок показывает картину в рамке, не на весь кадр. Фото учёных и обложку книги не использовать; обложку чужой книги и логотипы приложений не показывать.
4. Проверка: `python3 check_text.py configs/<имя>.py` (грамматика + голос; внимание: `check_voice.py` требует transformers — вместо него `check_voice_fw.py`, варианты: `printf 'фраза\n' | python3 check_voice_fw.py configs/<имя>.py -`). Не ошибка: имена, числа цифрами («1974»), безударные е/и. Ловушки: окончания «-ой/-ое», «наша → наши», «к зависимостям → экзависимостям», дефисные слова («парашютист-новичок»). Ударение `+` ставить на **правильный** слог («С+оломон»).
5. Длина: цель ≤ 60 с (≈ 110–125 слов с паузами `_voice3` дают ≈ 55–60 с). Проверить длительность — печатается `длительность N с` в начале рендера. Слишком длинно — резать фразы, не ускорять голос.
6. Концовка (просьба пользователя 21.10): отдельная финальная сцена с призывом «Отправь тому, кто …» + «Подпишись …» (озвучка + надпись + `SUB_PLATE`); в 1.3 ещё «Сохрани». Функция `cta_card(...)` есть в `dopamine_1.py`.
7. Превью: `python3 cinema_engine.py configs/<имя>.py <имя>.mp4 1,6,12,…` → `work/<имя>/pv_*.png`; **смотреть кадры** (перекрытия текста, длина строк, зоны интерфейса). Затем полный рендер ≈ 10 мин (три можно параллельно на 4 ядрах) → `python3 finalize.py <имя>` (−14 LUFS, `hq/<имя>_hq.mp4` ≈ 28,6 МиБ, обложка вшивается). `finalize` — только после полного окончания рендера. Цепочку запускать фоном: `setsid nohup bash -c "…" &`, ждать `until grep -q END …` в фоне; не использовать `pkill -f` по тексту собственной команды (убивает свой шелл).
8. Обложка: `python3 make_cover_term.py <картина> <cx> <cy> <высота> "СТРОКА 1" "строка 2" NN_<имя>_click` (логотип «МЫСЛИ ВЕКОВ» не должен закрывать лицо — при необходимости подложить тёмное поле сверху, пример `art/_greco_pad.jpg`).
9. Описание: `work/<имя>/caption.txt` = подпись + призыв + 3–5 хештегов; дисклеймер «Образовательный ролик, не медицинская рекомендация. Источники — в закреплённом комментарии.»; закреп `pinned_comment.txt` со ссылками из `15_sources.md`; `rights.txt` с лицензией музыки. Папка `work` в `.gitignore` — копию положить в `plan/dopamine_week/published_<дата>/`.
10. Пользователю в чат: `SendUserFile` — `hq/<имя>_hq.mp4`, обложка, описание, закреп. Ничего не публиковать без «да».

## Правила достоверности и прав (обязательно)
- Книга Лембке «Дофаминовая нация»: **текста нет**, цитат и пересказа глав в роликах нет; её имя — только в подписи 1.1 как «для чтения». Не приписывать Лембке то, что нельзя подтвердить (срок 30 дней, виды самосвязывания, роль стыда — убрано). Образ «весов» Лембке не использовать; «гремлины», «качели», истории пациентов — запрещены. Старые `configs/dopamine_scale.py`, `knopka.py` (по мотивам книги, с её именем в шапке) не публиковать без отдельной проверки.
- Науку брать только из `15_sources.md` (проверено по аннотациям/обзорам, не по полным текстам — открыть оригиналы перед публикацией, особенно Соломон и Корбит); гипотезы называть гипотезами, аналогии — аналогиями; не писать «дофамин — гормон счастья», «детокс очищает мозг», диагнозов, обещаний. Тексты о здоровье — с оговоркой о враче (холод, отказ от веществ, нагрузка).
- Не использовать: Ariely & Wertenbroch 2002 (проблемы воспроизведения), Sepah как автора термина (не проверен).
- Музыка: **только CC0** — Бах, Ария, Kimiko Ishizaka (Open Goldberg Variations), `music/ogv_aria.mp3`, лицензия и ссылка в `rights.txt`. Записи Musopen — не использовать, пока лицензию конкретной записи не подтвердит пользователь. Нет подтверждённой лицензии → `NO_MUSIC = True` в конфиге (движок пишет тишину вместо музыки). Указания авторства недостаточно для чужих материалов без лицензии.
- Картины — The Met/AIC CC0; перед рендером `used_art.py`; репродукции с лицензиями «NC» (например Британский музей) не брать.
- Правила платформы: ИИ-голос/ИИ-контент — отметить при публикации; тема самоповреждения (удар током в 4.2) — только как факт исследования, без инструкций.

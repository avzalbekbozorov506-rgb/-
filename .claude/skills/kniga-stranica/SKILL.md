# Стиль «Чтение страницы» (утверждён и сохранён пользователем 22.10.2026)

Образец-референс пользователя: ролик, где снята страница книги, палец ведёт по строкам, снизу заголовок. Копировать чужие кадры и текст нельзя —
делаем свою страницу и свой текст (общедоступные книги, свой перевод). Первый ролик в стиле: `mach_liar` («Он лгал всю жизнь. И ему верили»,
https://www.instagram.com/reel/DexZFW3gENQ/, 54,7 с).

## Что входит в стиль
- Страница рисуется скриптом `reels/art_tools/gen_book_page.py`: бумага (тёплая, с шумом и виньеткой), сверху «ГЛАВА …» + название главы, текст
  шрифтом Cormorant 84 px с выравниванием по ширине, поля 270 px (чтобы при зуме 1.3–1.4 текст не обрезался), подпись внизу «Автор. «Книга». Перевод свой».
- На каждой сцене — своя картинка `art/page_<имя>_<n>.jpg` с жёлтым маркером на нужной фразе (`SPANS = {n: (начало, конец)}`); камера движка
  приближает и ведёт к маркеру: `Z(fy)` в конфиге, fy ≈ (вертикальный центр маркера, печатается скриптом) + 0,10, чтобы маркер был в верхней половине
  кадра (внизу субтитры и тёмный градиент); для самых нижних строк fy ≈ 0,86.
- Конфиг — `reels/configs/mach_liar.py` (образец): `from _voice3 import *`, музыка спокойная (Шуберт `music/schubert_d959_andantino.mp3`, старт 0; Бах «Ария»),
  без `DRUM`; ХУК — плашка на первой сцене; концовка — призыв «Отправь тому, кто…» + «Подпишись», `SUB_PLATE`.
- Обложка — `make_covers_liar.py` (страница с маркером, `crop("page_..._2", …)`, плашка внизу), файл `covers/<NN>_<имя>_click.jpg`.

## Как сделать новый ролик в этом стиле
1. Скопировать `gen_book_page.py` под ролик (новый `TEXT`, `SPANS`, заголовок, подпись, префикс файлов `page_<имя>_`), запустить — печатает центры маркеров.
2. Скопировать `configs/mach_liar.py`, поменять сцены (озвучка с `|`), `Z(fy)` по центрам маркеров, хук, `HEAD`.
3. Цитаты — только общедоступные тексты, перевод свой; в описании «перевод свой», сверить с изданием.
4. Дальше обычный путь проекта: `check_text.py` → превью `cinema_engine.py … 1,8,20,30` → полный рендер → обложка → `finalize.py`.
Правила проекта (бесплатно, факты с источником, первые 3 секунды, «Отправь…» + «Подпишись») действуют как обычно.

# Авзал2 — формат «Клод и Авзал»

Отвечай по-русски, коротко. Работать самому, без команды агентов. Публиковать и ставить в расписание — только по явному «да» на конкретный ролик и время.

## Что это
Кубические («воксельные») 3D-герои: Клод (кирпично-красный куб) и мальчик Авзал (кепка, светлый свитер). Плашка сверху весь ролик, субтитры внизу, рот по громкости речи, моргание.
Имя «Авзал» — только для общения с пользователем. В озвучке, субтитрах и описаниях роликов его НЕ использовать (в ролике — «мальчик»).
Первый ролик (`claude_1000_years`) вышел 16.10.2026 в 08:00 через Metricool. После суток сравнить просмотры, досмотр, пересылки с историями и решить, добавлять ли формат в план.

## Где всё лежит (основная ветка `claude/vika-aptek-training-fjaa3t`)
- `reels/cubes/` — рендерер на numpy, без Blender (`cuberender.py`), персонажи (`cast.py`), предметы (`props.py`), сцены (`scenes*.py`, `scene_room.py`), голоса (`voices.py`), сборка (`video.py`), README с деталями. Прочитать README перед работой.
- `reels/scripts/claude_*.md` — сценарии: `claude_1000_years.md` (вышел), `claude_cars.md`, `claude_salary.md` (в Metricool на 16.10 13:00), `claude_quiz.md` (викторина, ждёт «утверждаю»), `claude_1000_years_v2.md` и `tupoy_vopros_1.md` («Тупой вопрос», юмор со счётом, ждёт решения).
- Не нужны: Blender, `reels/b3d/`, `pixar_kit.py`.
- Если в локальном клоне нет `reels/cubes/` — клон устарел: `git fetch origin claude/vika-aptek-training-fjaa3t` и влить в ветку сессии.

## Голоса (утверждены 16.10, не менять без просьбы)
Авзал — Vosk диктор 2, rate 0.98, pitch 1.14. Клод — диктор 4, rate 0.90, pitch 1.00 (голос C проекта). Другие герои — по таблице в README. Ударения через `+`. «…» синтезатор не принимает. Музыка — Бах «Ария», −14 LUFS.

## Правила сценария
- Интрига/хук в первую секунду (плашка = первая фраза), счёт или вопрос для досмотра, финал: «Отправь тому, кто …» + «Подпишись — тут история смешнее, чем в учебнике».
- Юмор: Клод подкалывает мальчика. Грубость мягкая: «тормоз», «балбес», «дубина»; живой мат нельзя (режет охваты). Цензурный гэг — звук «бип», в субтитрах «БИП». Без «дебил/идиот/тупица». Без насмешек над людьми, народами, религией, современной политики.
- Только проверяемые факты с источником (в описании). Описание без хештегов, первая строка — хук.
- Проверка до рендера: грамматика (LanguageTool) + голос (Whisper) на каждой реплике.
